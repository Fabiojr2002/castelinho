## 🚀 Como Executar e Visualizar

### Opção 1: Abrir diretamente no Navegador
Dê um duplo clique no arquivo `index.html` ou clique com o botão direito e selecione **"Abrir com" -> Google Chrome / Microsoft Edge / Firefox**.

### Opção 2: Servidor Local (HTTP Server)
Você pode rodar via terminal dentro desta pasta:
```bash
# Com Python:
python -m http.server 8080

# Ou com Node.js:
npx serve
```
Em seguida, acesse no navegador: [http://localhost:8080](http://localhost:8080)
